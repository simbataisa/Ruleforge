## Key Decisions Made

- AES-256-GCM credential encryption; key from `WEBHOOK_CREDENTIAL_KEY` env var (ADR-007)
- Strategy pattern for auth injection — zero changes to `WebhookDeliveryService` when adding new types (ADR-008)
- On-demand SQL aggregate for metrics — no background job, compound index handles scale (ADR-009)
- OAuth 2.0 + Custom Header deferred to v2 (PO decision; too complex for MVP sprint)
- Backward compat: POST with `secret` (no `authType`) infers `SIGNING_SECRET` — zero breaking changes
- `secret` column NOT dropped in this epic — removed in v2 after transition period
